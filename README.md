# Industrial Defect Detection & Quality-Control Assistant

Bharat AI-SoC Challenge 2026-27 — Problem Statement 5

An offline-capable steel-surface defect detection prototype using Raspberry Pi 5.

## Technologies
- YOLOv8 Nano with NCNN for defect detection
- ExecuTorch with Llama 3.2 1B for inspection explanations
- Streamlit dashboard with SQLite inspection history and CSV export

## Limitations
Research prototype only. Human inspection is required for QC decisions.
